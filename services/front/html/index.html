WoodyToys

Architecture microservices (TP9) — passerelle API, cache Redis, broker de messages.

Points d'entree

  • GET /api/misc/heavy?name=test — traitement lourd, mis en cache 30 s
  • GET /api/misc/time
  • GET /api/products/last — lecture base, mise en cache 15 s
  • GET /api/orders/status
  • POST /api/orders/do — corps JSON {"order": "Yoyo"}, traitement asynchrone

Les ressources statiques volumineuses sont servies via le CDN (cdn.l1-6.tonyephec.cloud).
